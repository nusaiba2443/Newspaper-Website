# THE DAILY EDIT
A premium, single-page digital newspaper / editorial magazine concept.

## Included
- Responsive editorial homepage with lead story and supporting features
- Breaking-news style briefing ticker
- Category filters and live story search
- Story reading modal with demo-content notice
- Save-for-later reading list persisted in localStorage
- Light / dark theme toggle persisted in localStorage
- Responsive mobile navigation
- Newsletter demo form with on-page confirmation
- Scroll-friendly sections for world, business, technology, culture, lifestyle and opinion

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Notes
This is a frontend portfolio demonstration. The sample editorial stories are illustrative and are not live news reporting. The newsletter form does not send data to a server. Images and Google Fonts load from external services, so an internet connection is needed for the full visual experience.
